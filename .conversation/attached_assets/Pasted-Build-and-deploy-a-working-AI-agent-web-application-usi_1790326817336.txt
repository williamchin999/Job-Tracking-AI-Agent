The application should be a lightweight personal "Gemini Enterprise" style AI agent that can connect to Google Gmail and Google Sheets, understand information across them, and propose actions.

APPLICATION GOAL
================

Build a personal AI agent that can perform this workflow:

User:

"Find recruiter emails from the last 7 days and add new opportunities to my job application spreadsheet."

The agent should:

1. Search Gmail
2. Read relevant emails
3. Identify potential job opportunities
4. Extract company, role, recruiter, email, date, and status
5. Find the user's Job Applications Google Sheet
6. Read existing rows
7. Detect likely duplicates
8. Show proposed changes
9. Ask the user for approval
10. Only after approval, update Google Sheets
11. Report what was changed

The application should feel like a small personal AI assistant rather than a basic chatbot.

========

The agent should have access ONLY to explicitly registered tools.

The agent must NOT be allowed to:

* execute Python
* execute shell commands
* make arbitrary HTTP requests
* access arbitrary files
* directly access OAuth credentials

Available tools:

READ ONLY:

search_gmail

append_sheet_row

The AI can automatically execute READ tools.

WRITE tools require human approval.

==================================================
AGENT LOOP
==========

Implement the following loop:

1. User sends a message
2. Python backend sends message to Gemini
3. Gemini determines whether a tool is necessary
4. If a READ tool is requested:

   * validate arguments
   * execute tool
   * return result to Gemini
5. Gemini can request another tool
6. Continue until Gemini produces a final answer
7. Return final answer to frontend

For WRITE tools:

1. Gemini requests the write operation
2. Backend validates the request
3. DO NOT execute it
4. Create an approval request
5. Return proposed action to frontend
6. User clicks Approve
7. Backend executes the write
8. Return result to user
